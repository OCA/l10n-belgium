This module allows to import products from Belgian Medipim API.

This module import products as unique product variants.

This allows to fill in:

- Product name (and translations)
- Product CNK
- EAN
- Sellable
- Product State
- Product Image
- Product Weight

Other modules are available to fill in other fields (see \*website_sale,
\*website_sale_stock modules)

Use Cases / Context
===================

In Belgium, pharmacists should be able to sell the whole catalog of
available products on the market. So, they should be able to retrieve
it. Medipim is one of those means as they provide an API to get products
and their characteristics.

See: https://docs.medipim.be/

Configuration
=============

Fill in the Connector source API configuration fields.

The filter can be configured in ``Data`` json section.

Usage
=====

See connector_importer and connector_importer_api modules.
