Context : this modules is made in order to use Peppol electronic invoicing. 

This module will auto-configure the parameters *UNECE Tax Type*, *UNECE Tax Category* on some taxes that come from the *l10n_be* module.
This module is incomplete :
- UNECE Due Date are missing
- all taxes are not covered, only the main sales taxes. 

The structure of this module is copied from : l10n_fr_account_tax_unece
