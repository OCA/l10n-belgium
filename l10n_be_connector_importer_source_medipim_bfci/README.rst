in order to manage BFCI categories.

Configuration
=============

See ``connector_importer_api`` module for configuration. A recordset for
BFCI categories is created by default. Configure the data filter to
configure your query to your needs.

Usage
=====

- Launch the import manually or define a cron to automatize the process.
